# Using the shelf

Press **⇧⌘V** (change it in Settings › Shortcuts) or click the menu bar icon ›
**Open Paste**. The shelf slides up from the bottom of the screen the mouse is
on. It takes the keyboard without activating Paste, so the app you came from
stays frontmost and receives the paste. Click outside it, switch apps, or press
**Esc** to close it.

Each card shows the item's type, how long ago you copied it, and the icon of the
app it came from. The header takes that app's color.

| Kind | Card shows |
| --- | --- |
| Text | the text, with formatting kept (RTF/HTML) for pasting |
| Link | the page title and preview image, fetched once |
| Image | a thumbnail and its pixel size |
| File | a QuickLook thumbnail and the path |
| Color | a swatch for hex colors like `#1A5CF2` |

## Keyboard

| Keys | Action |
| --- | --- |
| ← → | move between cards |
| ⇧← ⇧→ | extend the selection |
| ↩ | paste the selection |
| ⇧↩ | paste as plain text |
| ⌘1 … ⌘9 | quick paste the first nine cards |
| Space | preview |
| type anything, or ⌘F | search |
| ⇥, ⌘← ⌘→ | previous / next list (Clipboard, then each pinboard) |
| ⌘C | copy to the clipboard without pasting |
| ⌘E | edit text |
| ⌘R | rename the card |
| ⌘D | duplicate |
| ⌘N | new text item |
| ⌫ | delete |
| ⌘A | select all |
| ⌘, | settings |
| Esc | close |

The quick paste and plain text modifiers can be changed in Settings ›
Shortcuts, which also has this list as a cheat sheet.

## Mouse

- Click to select; ⌘-click and ⇧-click to select several.
- Double-click to paste.
- Right-click for the item menu: paste, paste as plain text, copy, pin,
  add to Paste Stack, edit, rename, duplicate, share, delete.

## Pasting several items

Select more than one card and press ↩: the text of every card is joined with
new lines and pasted at once, in shelf order.

## Drag and drop

Drag one card, or a whole selection, out of the shelf. It travels as a fanned
deck with a count badge. Where you drop it:

- **A text field or editor**: all text, links and colors arrive as one paste.
- **Finder or the desktop**: images and files arrive as real files.
- **A pinboard tab**: the cards are pinned there.
- **The Paste Stack**: the cards join the stack.

## Search and filters

Start typing to search content, titles, link titles, file paths and app names.
The filter button narrows results to a type (text, links, images, files,
colors) or a source app.

## Pausing

The shelf's ⋯ menu and the menu bar icon can pause collection for a while.
Anything you copy while paused is not saved.
